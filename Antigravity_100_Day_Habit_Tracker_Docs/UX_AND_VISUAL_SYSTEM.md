# UX and visual system

## Art direction
Personal Max Verstappen / racing mindset: focused, precise, competitive, calm under pressure. Use a premium dark interface with deep charcoal/navy, white text, racing-red accent, muted slate surfaces, and limited telemetry-inspired lines. Avoid clutter, fake speedometers, or excessive gradients.

## Components
- App shell with compact sidebar on desktop and bottom navigation on mobile.
- Dashboard metric cards with clear labels and definitions.
- 100-day streak strip/calendar.
- Daily check-in stepper with autosave feedback.
- Habit rows with accessible checkbox/toggle.
- Skill/task tables with mobile card layout.
- Analytics charts with visible units, date range, and empty states.
- Daily motivation card with quote provenance label.
- Confirm dialog for destructive actions and import overwrite.

## Interaction rules
- One primary action per screen.
- Never use a streak-shaming message. Use recovery-oriented language after a missed day.
- Distinguish “Check-in complete” from “All habits complete.”
- Show saved/saving/error state.
- Support editing prior days while preserving original check-in timestamp and recording last edit.
- Respect reduced-motion preferences; no forced animation or sound.

## Copy style
Short, direct, encouraging, performance-oriented. No fabricated Max Verstappen quotes. Label original lines as “Racing mindset,” not as quotes by Max.

## Visual acceptance
Consistent spacing/type scale, high contrast, responsive layout, no horizontal overflow at 320px, charts remain legible, and all controls have keyboard focus states.

# 100-Day Habit Tracker — Antigravity Build Pack

Build a polished, responsive, personal 100-day habit and growth tracker inspired by Max Verstappen's racing mindset. Treat the uploaded `100_Day_Growth_Planner.xlsx` as the source of truth for the planning structure and schedule; do not invent missing spreadsheet content.

## Product outcome
A reliable daily system that helps the user complete 100 consecutive calendar-day check-ins, track habits and skill/task progress, and review honest analytics. The streak measures **check-in consistency**, not perfection: a day counts when the user checks in and closes it, even if some habits were missed. Never silently erase or reset history.
